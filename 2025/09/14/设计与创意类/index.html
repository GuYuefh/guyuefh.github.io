设计与创意类网站

发表于2025-09-14|更新于2025-10-16|网站
|总字数:1.7k|阅读时长:5分钟|浏览量:

这是一些设计与创意类网站网站。

对称光绘：http://weavesilk.com/

  在线对称光绘创作工具，支持调整对称轴数量与方向，可自定义颜色渐变参数，生成的图案支持导出为 PNG/JPG 格式，还能保存草稿下次编辑。操作仅需鼠标拖拽，无需设计基础。

免费学设计：https://method.ac/

  互动式免费设计学习平台，以游戏化关卡推进学习，包含 “布尔向量运算”“贝塞尔曲线”“色彩和谐” 等模块，每个关卡提供即时反馈。学完后可下载练习作品，无需安装软件，浏览器直接操作。

随机着色页：https://www.justcolor.net/random/

  在线随机着色工具，提供细分线稿模板，支持自定义画笔大小、颜色吸管工具，还能调整线稿粗细。完成后可直接打印或分享到社交平台。

生成渐变：https://gradients.app/zh/new

  专业渐变色彩生成工具，提供预设渐变库，支持自定义色值、渐变方向与过渡平滑度。可保存常用渐变到个人账号，还能直接生成 CSS 代码，无需额外转换。

ColorDrop：https://colordrop.io/

  专业配色方案参考平台，支持按色彩情绪筛选，每个配色方案标注适用场景。可查看相邻色、互补色搭配建议，生成配色卡片分享给团队，还能导出色值表。

Excalidraw：https://excalidraw.com/

  轻量手绘风格绘图工具，支持添加常用图形，可导入图片作为背景参考。支持多人实时协作，导出格式包含 PNG、SVG、PDF，还能保存到浏览器本地或 Google Drive。无需注册，打开即可使用。

中国色彩：http://zhongguose.com/

  中国传统色彩专题平台，收录数百种传统色，每个色彩条目包含 “色值信息”、“色彩渊源”、“应用案例”。支持按色彩明度、色相筛选，还提供 “色彩搭配建议”。

了解创作故事：https://www.itsnicethat.com/

  全球创意创作故事平台，覆盖领域包括平面设计、插画、摄影、动画、产品设计、建筑设计。每个创作故事包含 “创作者访谈”、“作品展示”、“创作工具与方法”。还会推荐新兴创作者，报道全球创意领域的展览、活动。

CocoMaterial：https://cocomaterial.com/

  一个免费开源的手绘风格矢量插画库，目前收录超 3200 张风格统一、充满手工温度的插画，覆盖复古、历史、自然、科技等多元主题，细节丰富且可单独拆解复用；它支持在线调整插画颜色、大小及局部元素，生成专属版本后可一键下载 SVG/PNG 格式，还配套专属字体确保图文风格统一，基于宽松开源协议允许个人与商业用途，用户更可提交插画需求参与社区共创，适用于视觉设计、教育科普、品牌营销及开发者界面美化，以独特的手绘质感区别于传统扁平图库，用 “不完美的手工痕迹” 为设计注入人情味。

33 台词：http://33.agilestudio.cn/

  一款以台词为核心的影视素材定位工具，能帮助用户通过输入台词精准找到对应影片及片段时间点。它对不同人群均有实用价值：视频创作者可借助其快速搜寻台词相关的影视素材，还能便捷制作台词截图；英语、日语等语言的学生或老师，能通过搜索特定句子、词汇，获取它们在影视中的真实使用场景，辅助语言学习，同时还有更多潜在使用场景可供用户探索开发。

Addog：https://www.addog.vip/

  专为广告从业者打造的一站式网址导航平台，聚焦品牌、策划、营销、创意、文案五大核心领域，整合全球广告行业优质资源。平台实时更新瑞幸苹果 C 美式推广、卫仕公益广告、苹果品牌微电影等热门广告案例，供用户获取创意参考；同时聚合国内外权威业内资讯平台，如海外的《Campaign Brief》《Adweek》、国内的《数英》《梅花网》，助力同步国际趋势与本土动态；还链接了《Campaign 中国》《ADGuider》《胖鲸智库》等覆盖策略、创意、营销的创意人社区，方便用户交流学习；此外，直接关联微博、微信公众号等常用媒体平台，便于开展传播工作，全方位解决广告人资源分散的痛点，实现 “找案例、看资讯、进社区、连媒体” 的高效服务。

碳素：https://carbon.now.sh/

  一款专注代码片段可视化的免费在线工具，无需注册且无广告，核心功能是将代码转换为美观高清的图片。支持手动输入、拖拽文件或粘贴代码，覆盖 200 + 主流编程语言并自动语法高亮，可自定义外观主题、字体、布局细节，生成最高 4K 分辨率的 PNG 或 SVG 格式图片，还能一键导出或分享至社交、技术平台。

森林电台：https://www.tree.fm/

  一款以 “全球森林实地声音” 为核心的疗愈系在线平台，无需注册且无广告，用户点击 “Listen to a Random Forest” 即可随机播放来自 39 个国家 / 地区的森林原生环境音，并自动匹配 Unsplash 的对应实景图，营造沉浸式 “数字森林浴” 体验；通过联动 Ecosia 支持全球植树项目传递环保理念，还允许用户通过合作平台投稿本地森林录音参与共创，同时支持 Chrome 扩展，仅存在首次加载稍慢、部分录音时长较短的小缺点，本质是 “自然疗愈与环保行动” 的连接器，让用户在聆听自然中放松，同时以微小行动守护森林。

pngimg：https://pngimg.com/

  一款专注于免费无背景 PNG 素材下载的资源平台，现有 113487 + 张免费素材且持续新增，按 30 + 大类精准分类，所有素材均为透明底免抠图格式，无需注册即可免费下载，能直接适配 PPT、海报、短视频等设计、办公、内容创作场景。
