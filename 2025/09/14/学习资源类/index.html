这是一些学习资源类网站。
聚焦技术学习、行业知识，补充教程体系、社区功能与行业适配，覆盖编程等领域的成长需求。

菜鸟教程：https://www.runoob.com/

  免费编程与技术的学习平台，教程覆盖全技术栈：前端开发、后端开发、数据库、移动开发、运维。每个知识点包含 “概念讲解”“代码示例”“在线编辑器”，还提供常见问题解答、实战项目。无需付费，打开即可学习，适合零基础入门编程，利用碎片化时间积累技术。

极客教程：https://geek-docs.com/

  极客学院旗下专注 IT 技术系统化学习的免费图文教程平台，堪称 IT 从业者的 “自学百科全书”，覆盖基础编程、前端开发、后端开发、大数据、人工智能、移动开发等 30 + 领域 100 + 技术点。它以 “知识图谱 + 实战路径” 构建学习体系，比如 Python 学习可按 “基础语法→Django 框架→Scrapy 爬虫” 递进，配套电商系统开发、推荐算法实现等企业级案例，技术热点能 7 小时内响应更新，所有教程免费且支持离线下载，由专业教研团队与 BAT 工程师维护，还允许用户提需求参与内容共创，是衔接 “知识学习” 与 “职业应用” 的实用工具。

懒人 Excel：https://www.lanrenexcel.com/

  一个专注于 Excel 学习与办公效率提升的实用平台，核心围绕 Excel 的函数公式、操作技巧、数据分析、VBA 编程、图表模板及数据透视表等核心需求，为职场人、学生及数据处理从业者提供 “即学即用” 的实操指南。网站内容以场景化需求为导向，涵盖从基础操作到进阶自动化的全流程：比如针对数据处理痛点，提供 “从文本中提取数字”“分列拆分单元格数据”“对比两列数据找异同”“按月汇总数据” 等实用公式，配套具体案例，公式可直接复制使用；针对自动化需求，详细讲解 VBA 编程全流程，从 “打开 VBA 编辑器”“插入 / 导出模块”“调试代码” 到 “自定义编辑器字体颜色”，覆盖从入门到进阶的 VBA 操作；同时还包含 Excel 基础技巧、版本新增功能等内容。整体教程步骤清晰、案例贴近工作实际。

力扣（LeetCode）：https://leetcode-cn.com/

  全球极客喜爱的编程刷题平台，题目按难度、标签分类，支持 20 + 编程语言。提供 “学习计划”，社区功能含 “题解区”、“讨论区”，还能参加周赛 / 双周赛提升竞技能力。

Stack Overflow：https://stackoverflow.com/

  全球最大开发者问答社区，覆盖所有编程语言与技术领域。用户可提问具体编程问题，回答者多为资深开发者，提供专业解决方案；也可搜索已有问题，支持按标签筛选。还能关注领域标签获取最新问题，是开发者解决技术难题的核心工具，也是技术成长中积累经验的重要社区。
